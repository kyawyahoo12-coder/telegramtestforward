# Telegram Auto Forwarder Bot 🚀

A powerful, fast, and reliable Telegram message forwarder built with **Telethon**.

Automatically forwards messages (including albums/media groups) from one or multiple source channels/groups to destination channels/groups with advanced features.

---

## ✨ Features

- ⚡ **High Performance** with proper async handling
- 📸 Supports **Albums / Media Groups** forwarding
- ✏️ Optional **Message Edit** forwarding
- 🚫 Custom **Blocked Words** filter
- ⏱️ Configurable delay to avoid rate limits
- 🔄 Smart **Flood Wait** handling
- 🐳 **Docker Support** (Recommended)
- 📊 Detailed logging
- 🔄 Auto-restart ready
